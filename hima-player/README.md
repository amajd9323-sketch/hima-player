# HEMA ROKSI PLAYER

مشغل Android للموسيقى والفيديو، بواجهة عربية RTL مبنية على React وTypeScript وVite وCapacitor.

## الميزات الحالية

- فحص ملفات Android الصوتية والفيديو، استيراد ملفات، بحث بالعنوان والفنان، المفضلة، الأحدث، المجلدات، وفرز المكتبة.
- Queue Pro: أضف للتالي، إزالة، ترتيب بالسحب على سطح المكتب أو الأسهم على الهاتف، وحفظ الطابور.
- Crossfade متداخل للموسيقى، تكرار Shuffle/Repeat، مؤقت نوم، سرعات متعددة، وحفظ موضع الكتب الصوتية والفيديو.
- HEMA Audio Lab: موازن 10 نطاقات، إعدادات مسبقة، Bass Boost، Reverb، توازن صوت تلقائي، وبروفايل EQ لكل مقطع.
- كلمات LRC متزامنة، استيراد LRC/TXT وضبط توقيت نصف ثانية، ترجمة فيديو SRT/VTT، وتخصيص حجم ولون الترجمة.
- إيماءات الفيديو للسطوع والصوت والتقديم، قفل اللمس، تدوير الشاشة، PiP حيث يدعمه الجهاز، وتكرار A–B.
- Hema Wrapped، سجل الاستماع، قائمة الأكثر تشغيلًا، Party Visualizer، وضع القرآن والكتب الصوتية.
- تعديل عنوان/فنان/غلاف للعرض داخل التطبيق فقط، وفحص تكرار: SHA-256 للملفات المستوردة أو بيانات الاسم/الفنان/الحجم/المدة لملفات MediaStore.
- خزنة محلية مشفّرة بـ AES-GCM وPBKDF2، Widget للشاشة الرئيسية، وأزرار تشغيل/سابق/تالي في إشعار Android.
- تصدير/استيراد الإعدادات والقوائم والـ metadata، وتصدير/استيراد قوائم تشغيل مستقلة.
- HEMA Online: لصق روابط YouTube (الفيديو العادي وShorts وLive) أو روابط TikTok الكاملة وتشغيلها داخل التطبيق عبر المشغلات الرسمية المضمّنة.

## بناء APK

```bash
npm install
npm run build
npm run sync
cd android
chmod +x gradlew
./gradlew assembleDebug
```

GitHub Actions يبني APK تجريبيًا عند كل push إلى `main`. اسم Artifact: `Hema-ROKSI-Player-APK`.

## AI DJ

يمكن ضبط متغير GitHub Actions `VITE_AI_URL` على endpoint يقبل `POST { prompt, titles }` ويُرجع `{ order: number[] }`. من دون endpoint صالح، التطبيق يستخدم ترتيبًا محليًا حسب الاسم والفنان وسجل الاستماع. لا تضع API key خاصًا داخل متغيرات Vite المكشوفة للعميل.

## حدود مهمة

- تعديل الاسم والفنان والغلاف لا يكتب Tags إلى الملف الأصلي؛ التغييرات محفوظة محليًا داخل HEMA.
- فحص SHA-256 الكامل متاح للملفات المستوردة فقط. ملفات Android MediaStore تستخدم بيانات metadata لأن قراءة bytes الأصلية غير مضمونة.
- فقدان رمز الخزنة يعني فقدان الوصول للمحتوى المشفّر. الحد الحالي للملف الواحد 120 MiB. ملفات الخزنة لا تدخل النسخة الاحتياطية العادية.
- النسخ الاحتياطي لا ينقل ملفات الصوت/الفيديو أو ملفات أغلفة الصور. استيراد Playlist يطابق المقاطع الموجودة في المكتبة الحالية.
- EQ وReverb وCrossfade وتوازن الصوت تعتمد على Web Audio؛ النتيجة تختلف حسب الملف والجهاز.
- شاشة السيارة الحالية واجهة داخل التطبيق، وليست تكامل Android Auto كاملًا. المزامنة السحابية التلقائية تحتاج backend وحسابات، وهي غير مضافة.
- مشغّل YouTube يجب أن يبقى ظاهرًا؛ ميزة الصوت المنفصل أو التشغيل الخلفي من فيديو YouTube غير مضافة التزامًا بسياسات YouTube. بعض الفيديوهات قد تمنع التضمين، وروابط TikTok المختصرة تحتاج الرابط الكامل.
- APK الحالي Debug وليس نسخة Play Store موقّعة للإصدار النهائي.
