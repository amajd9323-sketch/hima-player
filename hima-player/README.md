# HEMA ROKSI PLAYER

مشغل Android للموسيقى والفيديو، بواجهة عربية RTL مبنية على React وTypeScript وVite وCapacitor.

## الميزات الحالية

- فحص ملفات Android الصوتية والفيديو، استيراد ملفات، بحث بالعنوان والفنان، المفضلة، الأحدث، المجلدات، وفرز المكتبة.
- Queue Pro: أضف للتالي، إزالة، ترتيب بالسحب على سطح المكتب أو الأسهم على الهاتف، وحفظ الطابور.
- HEMA Mood DJ: ثمانية مزاجات محلية (تركيز، رياضة، رومانسي، ليل، طرب عربي، ذكريات، استرخاء وخلط) ترتب المكتبة حسب metadata والمفضلة وسجل الاستماع دون اتصال.
- Queue Pro: تراجع عن التغيير الأخير، حفظ الطابور كقائمة تشغيل، وإعادة تحميل القوائم المحفوظة. تبقى القوائم وصفية وتشير إلى ملفات الجهاز ولا تنسخها.
- Live Canvas: ثلاثة أشكال لمؤثر الصوت (أعمدة، مرآة، موجة) مع حفظ الاختيار، وإيقاف حلقة الرسم عندما يتوقف التشغيل لتقليل استهلاك المعالج.
- HEMA Drop: فتح قائمة المشاركة الأصلية في Android للملفات المستوردة ولملفات مكتبة MediaStore التي يمكن قراءتها، مع منح المستقبِل صلاحية قراءة URI. التوصيل الفعلي يعتمد على التطبيقات القريبة والجهاز؛ ملفات الاستيراد تستخدم Web Share إذا دعمها WebView وإلا التنزيل كبديل.
- Crossfade متداخل للموسيقى، تكرار Shuffle/Repeat، مؤقت نوم، سرعات متعددة، وحفظ موضع الكتب الصوتية والفيديو.
- تحكم اختياري بالسماعة: عند تفعيل «إيقاف عند فصل السماعة»، يستمع Android إلى ACTION_AUDIO_BECOMING_NOISY لإيقاف المقطع عند قطع خرج الصوت؛ لا يستأنف التشغيل تلقائيًا عند إعادة التوصيل.
- HEMA Audio Lab: موازن 10 نطاقات، إعدادات مسبقة، Bass Boost، Reverb، توازن صوت تلقائي، وبروفايل EQ لكل مقطع.
- كلمات LRC متزامنة، استيراد LRC/TXT وضبط توقيت نصف ثانية، ترجمة فيديو SRT/VTT، وتخصيص حجم ولون الترجمة.
- إيماءات الفيديو للسطوع والصوت والتقديم، قفل اللمس، تدوير الشاشة، PiP حيث يدعمه الجهاز، وتكرار A–B.
- Hema Wrapped مع إحصاءات محلية إضافية (عدد الأغاني الفريدة والمفضلة والأكثر تشغيلًا)، سجل الاستماع، قائمة الأكثر تشغيلًا، Party Visualizer، وضع القرآن والكتب الصوتية.
- تعديل عنوان/فنان/غلاف للعرض داخل التطبيق فقط، وفحص تكرار: SHA-256 للملفات المستوردة أو بيانات الاسم/الفنان/الحجم/المدة لملفات MediaStore.
- خزنة محلية مشفّرة بـ AES-GCM وPBKDF2، Widget للشاشة الرئيسية، وأزرار تشغيل/سابق/تالي في إشعار Android.
- تصدير/استيراد الإعدادات والقوائم والـ metadata، وتصدير/استيراد قوائم تشغيل مستقلة.
- HEMA Online: استقبال روابط من قائمة مشاركة Android أو فتحها مباشرة، دعم YouTube/Shorts/Live وTikTok والروابط المختصرة (محاولة التوسيع على Android)، مشغلات رسمية مضمّنة وتحكمات تتوافق مع كل منصة.
- تكامل YouTube Music: البحث عن الأغاني والفنانين والألبومات والقوائم، فتح روابط الموسيقى عبر Android App Launcher لمحاولة تسليمها إلى تطبيق YouTube Music المثبت، البحث بنقرة واحدة عن الأغنية الصوتية الحالية، وحفظ روابط YouTube Music في مكتبة HEMA.
- مكتبة روابط محلية: حفظ، أسماء مخصصة، مفضلة، سجل 100 رابط، طابور تشغيل، مشاركة الروابط، وتصديرها ضمن النسخة الاحتياطية schema v3.
- معرض ألوان مسمّى ببطاقات متجاوبة بدل نقاط صغيرة؛ تحسينات أزرار التحكم وتباعدها على الشاشات الصغيرة.

## بناء APK

```bash
npm install
npm run build
npm run sync
cd android
chmod +x gradlew
./gradlew assembleDebug
```

GitHub Actions يبني APK تجريبيًا عند كل push إلى `main`. اسم Artifact: `Hema-ROKSI-Player-APK`.

## روابط YouTube وTikTok

1. لروابط YouTube أو TikTok: افتح تبويب HEMA Online أو شارك الرابط إلى HEMA. الروابط المضمّنة قد تمنعها إعدادات الناشر.
2. لـ YouTube Music: اكتب اسم أغنية أو فنان واضغط «بحث في YouTube Music»، أو الصق رابط أغنية/ألبوم/Playlist من `music.youtube.com`.
3. زر «فتح الرابط في YouTube Music» يستخدم Android App Launcher لتسليم HTTPS URL للنظام؛ إذا لم يكن التطبيق مثبتًا أو لم يتعامل Android مع الرابط كتطبيق، قد يفتح الموقع بدلًا منه.
4. احفظ الروابط، أضفها للمفضلة أو للطابور، وأعد فتحها من السجل. يمكن البحث بنقرة واحدة عن الأغنية الصوتية الحالية في مكتبة HEMA.
5. تكامل YouTube Music عبارة عن فتح وبحث عبر المنصة الرسمية؛ لا يزامن مكتبة حساب Google ولا يتحكم بتشغيله عن بُعد.

## AI DJ

يمكن ضبط متغير GitHub Actions `VITE_AI_URL` على endpoint يقبل `POST { prompt, titles }` ويُرجع `{ order: number[] }`. من دون endpoint صالح، التطبيق يستخدم ترتيبًا محليًا حسب الاسم والفنان وسجل الاستماع. لا تضع API key خاصًا داخل متغيرات Vite المكشوفة للعميل.

## حدود مهمة

- تعديل الاسم والفنان والغلاف لا يكتب Tags إلى الملف الأصلي؛ التغييرات محفوظة محليًا داخل HEMA.
- فحص SHA-256 الكامل متاح للملفات المستوردة فقط. ملفات Android MediaStore تستخدم بيانات metadata لأن قراءة bytes الأصلية غير مضمونة.
- فقدان رمز الخزنة يعني فقدان الوصول للمحتوى المشفّر. الحد الحالي للملف الواحد 120 MiB. ملفات الخزنة لا تدخل النسخة الاحتياطية العادية.
- النسخ الاحتياطي لا ينقل ملفات الصوت/الفيديو أو ملفات أغلفة الصور، لكنه يشمل مكتبة الروابط (YouTube/YouTube Music/TikTok) من schema v3. استيراد Playlist يطابق المقاطع الموجودة في المكتبة الحالية.
- EQ وReverb وCrossfade وتوازن الصوت تعتمد على Web Audio؛ النتيجة تختلف حسب الملف والجهاز.
- شاشة السيارة الحالية واجهة داخل التطبيق، وليست تكامل Android Auto كاملًا. المزامنة السحابية التلقائية تحتاج backend وحسابات، وهي غير مضافة.
- لا توجد واجهة YouTube Music عامة ورسمية تمنح HEMA مزامنة كاملة لمكتبة الحساب أو تحكمًا في تشغيله. الربط الحالي يبحث ويفتح روابط المنصة، ولا يفصل الصوت أو ينزّل محتوى YouTube ولا يشغّله بالخلفية، التزامًا بسياسات المنصة. بعض الفيديوهات قد تمنع التضمين، وروابط TikTok المختصرة قد تحتاج الرابط الكامل.
- APK الحالي Debug وليس نسخة Play Store موقّعة للإصدار النهائي.
